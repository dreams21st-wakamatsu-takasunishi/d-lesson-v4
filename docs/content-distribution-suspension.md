# 教材・音源の配信停止と再開条件

2026-10-27: 利用許諾の確認中につき、既存Word教材PDFと外部音源の配信を停止する。

2026-10-28更新: 運営者から音源がフリー素材であり従来仕様に戻す旨の指示を受け、リズム音源のみ再開する。Word教材のPDF表示とDrive共有は停止を継続する。以下の停止手順は緊急停止・履歴用であり、現在の音源配信状態とは区別する。

## リズム音源の再開

- `supabase/sql/resume_rhythm_audio.sql` で音源バケットを従来の公開設定へ戻し、停止用RESTRICTIVEポリシーだけを削除する。
- `CONTENT_DISTRIBUTION.rhythmAudioSuspended` を `false` にして、曲選択・再生・管理画面での音源アップロードを従来どおり有効にする。
- アップロード・更新・削除の既存管理者ポリシーは維持する。Word成果物のバケットと児童データの権限には変更を加えない。
- 公開音源はURLを知っている第三者も取得できる従来仕様である。素材の出典・規約・必要なクレジットの保管は継続する。今回、開発側で素材規約を独立に審査したものではない。
- Wordの停止を解除するSQLではない。Google Driveへのログインを必要とする閲覧案は別途検討し、所有者アカウントを児童端末に配らない。

## 停止対象と保持するデータ

- Word教材の外部URLを公開フロントから取り除き、PDF起動ボタンを停止する。
- Wordの8ステージのID、進捗、先生確認、提出機能は維持する。
- 既存リズム曲の選択・再生・管理画面でのアップロードを停止する。
- 音源Storageを非公開にし、匿名・認証済みの両方に対して対象バケットの読み書きを制限する。管理用service roleは引き続き保守できる。
- 音源・譜面・学習記録は削除しない。他のStorageバケットには制限を追加しない。

## 配信元の操作

`supabase/sql/suspend_unverified_media.sql` が対象バケットのみを停止する。既存の許可ポリシーより優先されるRESTRICTIVEポリシーを追加するため、非公開化だけを行う場合と異なり、登録済み利用者によるダウンロードや署名URLの新規発行も制限される。

Google Driveの共有設定は別管理である。アプリのリンク削除だけでは旧URLを無効化できない。所有者が対象8件の一般的なアクセスと個別共有・親フォルダからの継承を確認し、配信を停止する必要がある。ファイルは削除しない。

既に利用者が保存したファイル、端末や中継サービスのキャッシュ、発行済みで有効期限内の署名URLがある場合は、別の制約がある。今回の変更で過去の複製まで回収できるとは説明しない。

## 再開条件

1. 素材ごとに出典・権利者・許諾根拠・利用者範囲・期限・改変可否を確認する。
2. 権利台帳と配信対象校舎の対応を保存する。
3. 必要に応じて非公開保管、サーバ側認可、短時間の署名URLによる配信を実装する。
4. 停止用ポリシー・フロントの固定停止フラグ・ボタン表示を、一括で確認してから変更する。権利確認なしに一部だけ解除しない。
5. 架空児童で校舎境界、旧URL、提出・承認、既存進捗の保持を回帰試験する。

非公開化はアクセス対策であり、無許諾の複製や配信を適法にする手続きではない。

## 代替の方針

- 第一候補は独自に書き起こしたWord課題と、既存楽曲を使わない短い拍・打音のリズム課題。
- 既存教材の文章・図版・章別課題を改変して流用せず、習得技能から独立して設計する。
- 新教材は版を管理し、旧教材のクリアを新教材のクリアへ無条件に読み替えない。旧進捗は保持する。
- 権利者から配信許諾を得た教材を継続する案も残す。対象人数・校舎数・オンライン配信・ダウンロード可否を契約で確認する。
