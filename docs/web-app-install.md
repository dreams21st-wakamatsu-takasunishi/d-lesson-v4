# DレッスンをWebアプリとして使う

1. ChromeまたはEdgeで、いつものDレッスンのURLを開く。
2. ログイン画面に「アプリとしてインストール」が表示されたら押す。このボタンが表示されない場合は、ブラウザのアドレスバーのインストールアイコン、またはメニューのアプリのインストール項目を使う。
3. ブラウザの確認画面で「インストール」を選ぶ。以降はWindowsのスタートメニューから「Dレッスン」を起動できる。

通常のブラウザタブでも引き続き利用できる。インストール後も同じ児童番号やアカウントでログインする。アプリ起動時にログインが必要な場合がある。クラウド上の記録は同じアカウントに紐づき、インストール操作で移行・削除されない。

このアプリはオンライン利用が前提。Dレッスン独自のオフラインキャッシュやサービスワーカーは使用しない。端末へのインストールはブラウザでの確認が必要で、自動では行わない。

現在の公開パスを起動URL・アプリの識別子として使う。公開パスを変更する場合は、インストール済みアプリへの影響も確認する。

## 開発・公開確認

- `npm.cmd run check:release` でビルドしてから `node scripts/check-web-app-build.mjs` を実行し、マニフェスト、GitHub Pagesのサブパス、PNGアイコンを検証する。
- Chromiumの通常プロファイル（プライベート閲覧以外）で、インストールの表示、専用ウィンドウでの起動、ゲストでの動作を確認する。公開時は本番URLでも確認する。
