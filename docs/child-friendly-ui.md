# 児童向けUIの方針

- 共通の見た目は `src/styles/interface.css` で調整する。練習中の的・キー・判定表示の寸法や配色は、各ゲームの設定を維持する。
- 本文は同梱の M PLUS Rounded 1c（500・700）を使う。外部フォントサービスへの通信は不要。Unicode範囲別のフォントをブラウザーが必要に応じて読み込む。ライセンスは `public/licenses/m-plus-rounded-1c.txt` に同梱する。
- 児童向けの入口は丸い文字、教科別の淡い背景と濃い文字、押し込めるボタンで表現する。次の練習は黄色で強調する。進捗やロック状態は色だけに頼らず、数字・言葉も残す。
- 画面表示と操作時に短いアニメーションを使い、ホームのアイコンを動かし続けない。`prefers-reduced-motion` では追加した移動・回転・拡大を止める。
- 管理画面と先生の承認ダイアログは通常のゴシック体を使い、確認作業の読みやすさを優先する。
- 変更後はPC、タブレット縦横、スマートフォンで文字のはみ出し・戻るボタンとの重なり・濃色テーマ・動きを減らす設定を確認する。
