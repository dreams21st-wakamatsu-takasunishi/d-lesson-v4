# 構成見直しと改善 (2026-09)

## 対象と構成

現行の `d-lesson-v4` を対象とする。疑似OS統合は凍結を継続。

- 起動: `src/main.js` → `src/app/bootstrap.js`。HTML向けの関数登録は `src/app/global-functions.js`。
- 画面: `index.html` の画面を `src/ui/screen.js` で切り替える。
- 練習: `src/games/`、ステージ定義は `src/data/constants.js`。
- アカウント・保存: `src/api/user.js` と `supabase/functions/`。Auth/RLSとゲストの保存境界を維持。
- 集計・案内: `src/utils/`。校舎・グループ別ルートは `standard-route.js`。
- 公開: GitHub ActionsからGitHub Pagesへデプロイ。

## 実施した改善

| 問題 | 対応 |
| --- | --- |
| ホームが管理者設定のおすすめ順を使っていない | ホーム・先生・管理者の進捗とコース判定を共通化 |
| 未解放のABC・Wordや復習が必要なテストを案内する | 開始できるコースだけをおすすめにし、テスト前の復習へ誘導 |
| おすすめから始めると別のカテゴリ・章へ戻る | 対象カテゴリと章を初期化してから練習を開始 |
| 章内案内が復習・未解放・完了を区別できない | 状態に応じた案内と、直接開始できるボタンに変更 |
| ローマ字一覧が未挑戦でもクリア済み表示 | 保存済みの実績に基づく表示に変更 |
| 非表示の旧おすすめUIと独立した判定処理が残っている | HTML、CSS、処理、グローバル関数登録を削除 |
| ことば練習ボタン内の文字と報酬位置が崩れる | 縦並びと位置基準を設定し、狭い画面ではテスト欄を折り返す |
| 1024px幅でホームがはみ出す、小画面でヘッダーが切れる | 中間幅のレイアウトと上部ボタンの折り返しを追加 |
| 古い作業フォルダの案内とブラウザ確認用ファイルが残る | READMEを訂正し、不要なスナップショットを削除・除外 |
| 公開時にローカルのリリースチェックの一部しか実行しない | GitHub Actionsも `check:release` を実行 |
| 記録日付のテストが日本時間のPCでしか通らない | ローカル日時からISO入力を作るテストに修正し、UTC環境でも確認 |

## 確認方法

- `npm.cmd run check:release`: 環境、管理者補助処理、進捗、入力、公開用ビルド。
- `check:learning-route`: 校舎・グループの優先順位、未解放除外、課題対象、旧Word記録、異常値、全完了。
- ブラウザ: ゲストの一時データで、初回おすすめ、復習、ことば練習、ABC、ローマ字一覧、開始・戻る操作。
- レイアウト: 1365×900、768×1024、1024×768、390×844。長い課題名と報酬バッジを含めて確認。
- ゲスト確認中にSupabaseへの書き込みリクエストがないことを監視。実児童・Auth・DBの変更は不要。

## 残る改善候補

1. `src/api/user.js` の認証画面・保存・校舎設定の分割。ロール別の実機確認を伴う独立した変更にする。
2. `src/style.css` とテーマ内の上書きCSSを画面単位で整理。色・印刷・きせかえの回帰確認が必要。
3. `src/ui/teacher-status.js` の画面生成と集計処理の分離。
4. 保存済みの `keyboardSequence` は順序の位置を表す。将来のステージ追加ではバージョン付き移行を導入し、既存進捗の解釈が変わらないようにする。
5. Supabaseの旧設定行や移行用スクリプトは、実際の利用状況を確認してから整理する。今回のファイル整理では削除しない。

本確認は全機能の監査や本番Auth/RLSの再検証を完了したことを意味しない。今回変更した導線と共通集計を中心に確認する。
